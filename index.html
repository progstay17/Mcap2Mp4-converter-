Bantuan

Pertanyaan umum.

Hal penting sebelum memulai konversi.

Apakah MCAP2MP4 gratis?

Installer versi 0.3.2 tersedia untuk diunduh dari repository GitHub proyek. Periksa repository untuk source code, dokumentasi, dan ketentuan lisensi yang tersedia.

Apakah semua file MCAP bisa dikonversi?

Tidak selalu. Konversi ditujukan untuk stream video H.265 dan layout pesan MCAP yang didukung. Hasil bergantung pada struktur serta codec dalam rekaman.

Apakah video di-encode ulang?

Jalur konversi utama dirancang untuk remux stream yang didukung, bukan melakukan encoding ulang. Codec atau layout yang tidak didukung mungkin gagal diproses.

Bagaimana jika installer atau player bermasalah?

Pastikan file terunduh dengan lengkap, simpan pesan error dan log aplikasi, lalu lihat FAQ troubleshooting. Ketersediaan fitur player dapat bergantung pada komponen media yang dibundel.

Di mana saya menemukan opsi CLI?

Jalankan mcap2mp4-cli.exe --help dari build yang terpasang. Untuk memeriksa versi, jalankan mcap2mp4-cli.exe --version.
